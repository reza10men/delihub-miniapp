# DeliHub Mini App

> قیمت لحظه‌ای تتر به تومان — داخل تلگرام

## Phase 1 — Initial Frontend

Single-card UI that displays a simulated USDT/TOMAN price with a refresh button.

### Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, @media queries)
- Vanilla JavaScript (ES2022+, no build step)
- [Telegram Mini Apps SDK v2](https://core.telegram.org/bots/webapps)
